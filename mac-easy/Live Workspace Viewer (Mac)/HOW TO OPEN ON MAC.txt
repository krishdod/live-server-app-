Live Workspace Viewer — Mac

One-click / double-click often fails on Mac (Gatekeeper + WhatsApp).
Use Terminal — this is the method that works.

==================================================
OPEN THE APP (working method)
==================================================

1. Open Terminal on the Mac (Spotlight → type Terminal → Enter)

2. Paste this block and press Return:

cd "$HOME/Downloads/Live-Workspace-Viewer-Mac/Live Workspace Viewer (Mac)" 2>/dev/null || cd "$HOME/Downloads/Live-Workspace-Viewer-Mac" 2>/dev/null || cd "$HOME/Downloads/Live Workspace Viewer (Mac)" 2>/dev/null || cd "$HOME/Desktop/Live Workspace Viewer (Mac)"
ls
xattr -cr .
chmod +x "Open Viewer.command"
bash "Open Viewer.command"

3. First run can take a few minutes (installs packages / builds).
   After that, the viewer window opens.

If cd fails:
- In Finder, open the folder that contains Open Viewer.command
- In Terminal type: cd 
  (with a space after cd)
- Drag that folder from Finder into Terminal, then press Return
- Then run:

ls
xattr -cr .
chmod +x "Open Viewer.command"
bash "Open Viewer.command"

==================================================
NEED NODE.JS?
==================================================
Install LTS from https://nodejs.org then run the same Terminal lines again.

==================================================
DO NOT
==================================================
- Do not rely on double-clicking Open Viewer.command
  (macOS often says "damaged" after WhatsApp)
- Prefer AirDrop / USB / Drive over WhatsApp when sending the zip
