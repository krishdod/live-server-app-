Live Workspace Viewer — Mac

If you see: "Open Viewer.command is damaged and can't be opened"
that is macOS security after WhatsApp — the file is NOT damaged.

==================================================
FIX (copy everything below into Terminal, press Return)
==================================================

Open Terminal on the Mac, paste this, press Return:

cd "$HOME/Downloads/Live Workspace Viewer (Mac)" 2>/dev/null || cd "$HOME/Desktop/Live Workspace Viewer (Mac)" 2>/dev/null || cd "$HOME/Downloads/mac-easy/Live Workspace Viewer (Mac)" 2>/dev/null || cd "$HOME/Desktop/mac-easy/Live Workspace Viewer (Mac)"
xattr -cr .
chmod +x start.sh "Open Viewer.command"
bash ./start.sh

==================================================
Do NOT use WhatsApp for the folder if you can avoid it
==================================================
WhatsApp often triggers the "damaged" warning.
Prefer AirDrop, USB, iCloud Drive, or email zip.

==================================================
Need Node.js?
==================================================
Install LTS from https://nodejs.org then run the Terminal lines again.
